## Overview

The VCAI2C02A is an I2C module designed for measuring current (0-50A) and voltage (0-50V) using a measuring transformer. It integrates multiple components to provide accurate and reliable measurements for various applications.

## Features

- **Current Measurement:** 0 to 50A
- **Voltage Measurement:** 0 to 50V
- **Interface:** I2C
- **Measurement Transformer:** Included
- **Connectors:** XT30PW-M and XT30PW-F
- **High Stability Isolated Error Amplifier:** ADuM3190
- **High-Resolution ADC:** MCP3423

## Components

### XT30PW Connectors

- **Item No:** XT30PW-M and XT30PW-F
- **Contact Resistance:** 0.80mΩ
- **Rated Voltage:** DC 500V
- **Rated Current:** 15A
- **Instantaneous Current:** 30A
- **Material:** Brass Gold Plated
- **Insulation Material:** PA, UL94 V0
- **Operating Temperature:** -20℃ to 120℃

### ADuM3190 Isolated Error Amplifier

- **Stability in isolated feedback applications**
- **Initial Accuracy:** 0.5%
- **Accuracy over Temperature Range:** 1%
- **Reference Voltage:** 1.225V
- **Bandwidth:** 400 kHz
- **Isolation Voltage:** 2.5 kV rms
- **Temperature Range:** -40°C to +125°C

### MCP3423 ADC

- **Resolution:** 18-bit
- **Interface:** I2C
- **Programmable Data Rate**
- **Internal Voltage Reference:** 2.048V

### Hall Effect Current Sensor (Tamura L01ZXXXS05 Series)

- **Type:** Open Loop
- **Mounting:** PCB
- **Nominal Current:** Up to 600A
- **Accuracy:** Excellent accuracy and linearity
- **Temperature Drift:** Low
- **Frequency Bandwidth:** Wide
- **No Insertion Loss**

## Applications

- **Linear Power Supplies**
- **Inverters**
- **Uninterruptible Power Supply (UPS)**
- **DOSA-compatible Modules**
- **Voltage Monitors**
- **Automotive and drone Systems**
